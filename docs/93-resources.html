Templates, solution guide, and reference material

Reference

This is the index of the collateral that goes with an OWP engagement — the data templates, the solution guide, and the documentation the presenters promised to follow up with. Most of these are distributed during the sales cycle and shared with the customer before kickoff, not published as public downloads, so use this page to know what exists and when to reach for it.

💡 When these get shared

The data templates, the solution guide, and the documentation are handed over during the sales cycle or when the deal is signed — and always before kickoff, via a shared drive. Aim for one or two template-review meetings with the customer before kickoff so the data conversation starts early.

Core delivery materials

These are the materials distributed during the sales cycle and at deal signing.

MaterialUsed For
OWP Data Templates (Excel workbook) Capturing the customer's data. One tab per object — position file, employee file, and so on — with each field flagged mandatory Y/N. The customer matches their data to it and reports what's available and what isn't. Data is then loaded via the app's import action.
Solution Guide The reference for what OWP does and how to deliver it. Shared with the templates during the sales cycle / at deal signing, before kickoff.
OWP Documentation Supporting product documentation shared alongside the solution guide before kickoff.

Promised follow-up materials

During the sessions the presenters said they would send the following after the workshop. They cover the parts of the security model that were referenced but not fully walked through on the recordings.

MaterialUsed For
Security / selective-access documentation The detail behind the selective-access model — how write access to an org cascades to underlying orgs and aligned positions, and how the security hub is managed in 2.1.
Selective-access walkthrough videos Recorded walkthroughs of configuring selective access, to complement the written documentation.
Full user-roles and page-security matrix The complete, cell-by-cell matrix of user roles against features and the UX page-security categories — which pages apply to which model and which role has access. The structure was shown in the session; the exhaustive matrix is being sent as documentation.
